PANDUAN WEBSITE ZONA-PS — BAHASA INDONESIA

Isi ZIP:
- index.html: halaman website berbahasa Indonesia
- style.css: desain gaming neon
- script.js: menu HP dan tahun otomatis

CARA MEMPERBARUI WEBSITE DI NETLIFY:
1. Ekstrak ZIP ini.
2. Buka dashboard Netlify dan pilih situs ZONA-PS milikmu.
3. Buka bagian Deploys / Penerapan.
4. Unggah folder yang berisi index.html, style.css, dan script.js melalui metode deploy manual yang tersedia.
5. Setelah deployment berhasil, buka kembali alamat situs untuk memeriksa perubahan.

Catatan:
- Nama tim masih contoh, silakan ubah sesuai nama anggota tim.
- Tautan Discord masih contoh. Ganti dengan tautan komunitas resmi.
- Bagian unduhan belum memiliki file atau tautan unduhan.
- Website ini belum memiliki panel admin atau database.
